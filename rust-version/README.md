# دفتر کارکرد — نسخه راست (Rust Version)
### سیستم مدیریت مالی کارگاهی، تراز و کارکرد ماشین‌آلات (اندروید، ویندوز و لینوکس)

این پروژه، بازنویسی کامل، سریع و امن سیستم **«دفتر کارکرد»** به زبان **Rust** بر پایه قواعد مالی نسخه ۳ (`business_rules_v3.md`) با معماری چندسکویی برای **Android**، **Windows** و **Linux** است.

---

## ۲. اجرای سریع و آزمون‌ها

### اجرای آزمون‌های طلایی هسته (Golden Tests G1 to G5):
```bash
cargo test --package karkard-core
```
تمامی تست‌های تطبیق تراز طلایی، اعتبارسنجی تریگرهای دیتابیس، تبدیل تقویم جلالی و محاسبات ریاضی عدد صحیح با موفقیت کامل پاس می‌شوند.

### اجرای سریع نسخه خط فرمان (CLI Demo):
```bash
cargo run --package karkard-cli -- demo
```
خروجی این دستور، سناریوی متوازن بخش ۵ قواعد مالی (امیر، عارف، راننده و کارفرمایان گوزل و هادی) را در حافظه اجرا کرده و تساوی طلایی را نمایش می‌دهد:
$$\sum \text{bal}(\text{حساب‌های پروژه}) + \sum \text{Rec}(c) = \sum \text{Due}(p)$$
$$۲۶٬۰۰۰٬۰۰۰ + ۳۰٬۰۰۰٬۰۰۰ = ۵۶٬۰۰۰٬۰۰۰ \text{ تومان ✓}$$

## ۳. ساخت و کامپایل برای هر سه پلتفرم

### الف) ساخت نسخه لینوکس (Linux x86_64)
```bash
./scripts/build-linux.sh
```
خروجی در مسیر `target/release/karkard-app` قرار می‌گیرد.

### ب) ساخت نسخه ویندوز (Windows x86_64 .exe)
با استفاده از تارگت `x86_64-pc-windows-gnu`:
```bash
./scripts/build-windows.sh
```
فایل اجرایی در مسیر `target/x86_64-pc-windows-gnu/release/karkard-app.exe` تولید می‌شود.

### ج) ساخت نسخه اندروید (Android APK / NDK)
اسکریپت از Android NDK موجود روی سیستم شما استفاده کرده و کتابخانه‌ها را برای ۳ معماری اصلی اندروید کامپایل می‌کند:
```bash
./scripts/build-android.sh
```
تارگت‌های تولیدشده:
- `aarch64-linux-android` (گوشی‌های مدرن ۶۴ بیتی)
- `armv7-linux-androideabi` (دستگاه‌های ۳۲ بیتی)
- `x86_64-linux-android` (شبیه‌سازها و تبلت‌های x86)

## ۴. ویژگی‌های برجسته پیاده‌سازی

1. **دقت محاسباتی بی‌نقص:** مبالغ تماماً عدد صحیح تومان هستند و تقسیم‌ها بدون ممیز شناور با `floorDiv` و روش Hamilton-Hare باقیمانده را بدون کسری از تومان توزیع می‌کنند.
2. **تریگرهای نفوذناپذیر دیتابیس:** قفل پروژه، ممنوعیت حذف فیزیکی، الزامی بودن دلیل حذف نرم و تطابق نقش شریک و کارفرما در سطح SQLite محافظت می‌شوند.
3. **طراحی واکنش‌گرا و مدرن (`/ui-styling`):** رابط کاربری تمیز با Tailwind CSS، تایپوگرافی چشم‌نواز با فونت وزیرمتن، کامپوننت‌های دسترسی‌پذیر و قابلیت چاپ تمیز صورت‌وضعیت به PDF.
